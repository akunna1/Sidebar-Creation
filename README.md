# Sidebar-Creation

Creating and styling a sidebar using **React.js** and **Material UI**.

---

## 🔗 Useful Links

* [Material UI Icons](https://mui.com/material-ui/material-icons/)
  *(Install MUI first using:)*

```bash
npm install @mui/material @emotion/react @emotion/styled
```

---

## 🧩 Project Structure

### `components/sidebar.js`

Renders a sidebar by **mapping over `sidebarData`** to generate clickable list items with **icons** and **titles**.

### `components/sidebarData.js`

Stores the **sidebar menu data** as an array of objects, each containing an icon and a title to be displayed in the sidebar.
